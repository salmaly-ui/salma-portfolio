## 📋 Aperçu

Ce portfolio met en valeur mon parcours de développeuse web full stack. Il est conçu pour être :
- **Responsive** : s’adapte à tous les écrans (mobile, tablette, desktop)
- **Performant** : build optimisé avec Vite
- **SEO-friendly** : gestion des métadonnées avec React Helmet Async
- **Modulaire** : composants réutilisables et données externalisées

## 🛠️ Stack technique

**Frontend**
- React 19 – bibliothèque UI
- TypeScript – typage statique
- Tailwind CSS – framework utilitaire
- React Router DOM v7 – navigation SPA
- React Helmet Async – SEO

**Outils de développement**
- Vite – build rapide
- ESLint + Prettier – qualité du code
- PostCSS + Autoprefixer – traitement CSS

**Déploiement**
- Vercel – hébergement et déploiement continu
